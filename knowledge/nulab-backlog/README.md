# Nulab Backlogチケット知見

銀行との依頼、質問、回答、合意を記録するNulab Backlogの要約を保存する。チケット本文の複製ではなく、PMOが現在地と判断材料をすばやく把握するための知見である。

## 構成

| 銀行 | チケット知見 |
|---|---|
| 大光銀行 | [taiko/](taiko/) |
| トマト銀行 | [tomato/](tomato/) |

## Product Backlogとの関係

- 銀行Backlogは、TID全体の最上位タスクではない。
- 各チケットには、対応する [TID Product Backlog](../product-backlog/README.md) または銀行プロジェクトを記録する。
- 銀行Backlogが複数ある場合も、同じProduct Backlogタスクへ紐付けてよい。
- Product Backlogが未登録なら、チケット知見に `要紐付け` と書き、Jiraキー・URLの確認を待つ。

新規作成・更新には [Backlogチケットテンプレート](../../templates/backlog-ticket.md) を使う。
