# TID Product Backlog

TIDチーム全体が抱える仕事の最上位一覧。Jira Product Backlogを原本とし、ここではチケットの目的、現在地、担当ボール、関連する銀行Backlogを要約する。

## 登録状況

Jiraの接続情報またはチケット一覧は未登録。取得後、以下の2分類で登録する。

| 分類 | 説明 | 例 |
|---|---|---|
| プロジェクト対応 | 銀行導入・大型案件など、特定プロジェクトに紐付く作業 | 大光Ph2.0のTID対応 |
| プロダクト対応 | TID共通機能、SDK、SRE、横断改善など | 認証基盤の改善 |

## 1タスクに記録する項目

| 項目 | 内容 |
|---|---|
| Jiraキー・URL | Jira原本へのリンク |
| ゴール・背景 | なぜ存在するタスクか |
| 現在地・期限 | 状態と予定完了日 |
| 担当ボール | 次に動くTID PRD、Berserkers、SDK、銀行、IBチームなど |
| 関連Nulab Backlog | 銀行とのやり取りがある場合のリンク |
| 関連議事メモ | 判断根拠・決定事項へのリンク |

新規登録には [Product Backlogタスクテンプレート](../../templates/product-backlog-item.md) を使う。
