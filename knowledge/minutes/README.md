# 議事メモ

会議の雑メモを、後から参照・検索・PMO判断できる形に整理して保存する。

## 保存ルール

- ファイル名: `YYYY-MM-DD-{銀行または領域}-{会議名}.md`
- 保存先: 銀行案件は `knowledge/minutes/{銀行ID}/`、横断会議はこのディレクトリ直下
- 元メモ、Slackスレッド、会議資料などの根拠URLを記載する
- 決定事項、未決事項、アクション、リスクを必ず分ける
- 関連するProduct Backlog、Nulab Backlog、銀行プロジェクトへリンクする

新規作成には [議事メモテンプレート](../../templates/meeting-note.md) を使う。
